Uploading Images

Use the Upload page to add images directly through your browser.

  • Select one or more files (JPEG, PNG, WebP, GIF, MP4, WebM, or a supported archive format : cbz or zip).
  • Optionally add tags that will be applied to all uploaded files.
  • Choose a destination folder (e.g. 2026/april) to place the files under; leave blank to save at the gallery root. Missing folders are created automatically.

From the gallery, open the Actions chooser (button next to the search bar, or press a) to save the search, add/remove tags, auto-tag, move, or delete every image in the current search. To scope an action to a few images, check their thumbnails and use the corresponding button in the batch bar.

Adding Tags

In the tag input on the image detail page:

  • Type one or more tags separated by spaces and press Add. Each whitespace-separated token becomes its own tag. Wrap a multi-word tag in double quotes to collapse internal spaces to underscores: "red hair" → red_hair. You can also use _ directly.
  • Use category:tagname to add a tag to a specific category.
  • Example: artist:"john doe" blue_eyes 1girl adds "john_doe" as an artist tag and "blue_eyes" and "1girl" as general tags.
  • Autocomplete suggestions appear as you type - use ↑/↓ arrows to navigate, Enter to select.

Tag names

  • Lowercase only: a-z, 0-9, _, (, ), !, @, #, $, ., ~, +, -, :, ?, <, >, =, ^
  • Maximum 200 characters.

Managing Tags

The Tags page is the catalog view.

  • Create tag declares a fresh tag (no image needed); useful for pre-seeding a vocabulary or wiring implications against unused names.
  • Create alias binds a name to an existing canonical so typing the alias adds the canonical instead.
  • Alias on a non-alias row turns it into an alias of another tag: every image-tag row moves to the canonical and the source becomes a zero-usage alias entry.
  • Implications declare "tag X also implies tag Y": adding X to an image fans Y out as a dim implied row.

Inbox

Every newly ingested or uploaded image lands in the inbox. Flip it to archived (curated) once you've reviewed the tags.

  • Gallery toolbar: the ✱ button left of the favorites toggle filters to the inbox.
  • Image detail: the ✱ button left of the favorite toggles the current image between inbox and archived.
  • Batch surface: the gallery's Actions chooser and the selection batch bar each carry a single Toggle inbox entry that flips every targeted row (inbox rows become archived; archived become inbox).

Rating & SFW Ceiling

Each image carries at most one rating tag: general < sensitive < questionable < explicit. A manual rating add overwrites whatever was on the image, even if the new level ranks below the existing one.

The footer carries the SFW ceiling: rating: sfw · sensitive · questionable · explicit. Click any level to hide images ranked above it.

Manga, Comics & Archives

CBZ and ZIP files containing images ingests as one library row, like an image. The cover thumbnail is page 1 (natural-sorted across the archive).

The detail page for an archive gains:

  • Read - opens the reader at page 1.
  • Pages - opens a thumbnail grid of every page; click a cell to jump straight to that page in the reader.
  • A read-only Comic / manga metadata panel parsed from ComicInfo.xml at the archive root, when present.

Keyboard Shortcuts

Press ? on any page to open the cheat-sheet overlay.

Settings & Maintenance

The Settings page provides:

  • General - toggle the gallery file watcher, set the max file size, and change the number of images per page.
  • Galleries - add, rename, switch between, set default, or delete configured galleries.
  • Auto-Tagger - enable one or more taggers, set global and per-category confidence thresholds, scope a tagger to a subset of galleries, toggle GPU (CUDA), pick a worker count, and disable or delete a tagger row.
  • Authentication - set or remove a password, regenerate the API token.
  • Maintenance - prune missing images, clean up orphaned thumbnails, rebuild thumbnails, recalculate tag counts, merge auto-tagged-only general tags into their unique categorized counterparts, re-extract metadata, vacuum the database, and list or remove duplicate file paths.
  • Schedule - opt-in daily automation. Pick a time-of-day and tick any of: Sync gallery, Remove orphaned thumbnails, Run enabled auto-taggers, Merge general tags. The scheduler iterates every configured gallery in turn at the chosen time.
  • Stats - read-only diagnostic block: process memory, per-gallery database size, and filesystem free space.
